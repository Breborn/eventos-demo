# Quinta Mirador — Maqueta Centro de Eventos & Parcelas (Breborn.cl)

Demostración editorial para centros de eventos, parcelas con piscina/quincho y banquetería en la V Región, con cotizador instantáneo de invitados y envío directo al WhatsApp.

- **Estilo combinado:** Estética editorial de matrimonios (tipografía clásica, tonos marfil/bronce) + UX comercial de capacidades, paquetes por formato y calculadora instantánea.
